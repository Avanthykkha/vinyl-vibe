# Vinyl by Avi

*A Vinyl-Inspired Music Streaming Experience*

## Overview

Vinyl by Avi is a modern music streaming web application inspired by the nostalgic experience of vinyl records. It combines an interactive vinyl player with personalized music discovery, playlist management, and a clean, minimalist interface to create an engaging listening experience.

---

## Features

-  Search songs and artists
-  Interactive vinyl music player
-  Like songs and build your personal library
-  Recently played history
-  Create and manage playlists
-  Follow favorite artists
-  Personalized "For You" recommendations
-  Editable user profile with persistent local storage

---

## Technology Stack

- **Frontend:** Next.js 15, React 19, TypeScript
- **Styling:** Tailwind CSS
- **API:** YouTube Data API v3
- **Player:** React YouTube
- **Storage:** LocalStorage
- **Deployment:** Netlify

---

## Design Philosophy

The application blends the classic charm of vinyl records with modern web technologies, focusing on simplicity, aesthetics, and personalization. Every element is designed to provide a warm and immersive music listening experience.
